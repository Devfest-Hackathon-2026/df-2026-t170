# ブラタモリ風ランダム旅行支援アプリ(仮)

現在地やランダムに指定された市区町村の観光を支援するWebアプリケーションです。

## 実行方法(開発用)
ローカルで以下を実行してください(`/devfest2026/`まで移動)。
バックエンド：

```
cd backend
uv run backend
```

`127.0.0.1:8000`を確認

フロントエンド：

```
cd frontend
pnpm run dev
```

`localhost:3000`を確認
