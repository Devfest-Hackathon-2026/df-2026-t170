# 画面遷移

1. スタート画面

アプリのコンセプト説明と、スタート方法を以下の2つを選択する。
- ランダム地点で観光
- 現在地で観光

ただし、MVPでは現在地の機能は使用しない。
ランダム地点の場合は`GET /municipalities/random`、現在地の場合は`POST /municipalities/from-geocode`、
して市区町村の情報を得て、2へ進む

2. 地点選択

1で取得した市区町村で、大きく地名表示＋上部に小さめのブロックでGoogle map表示。
また、下部には「戻る」「観光する」の選択肢を設け、1に戻るか、3に進む。
map表示には、Google Maps Javascript APIを用いてポリゴンとして描画。ポリゴンのパスは`GET /municipalities/{municipality_code}/map`から取得する。

3. 観光ガイド表示
上部に地名は表示し続ける。
2のスタイルのまま、大きく地名が表示されていた部分を各カテゴリごとで選択できるようにし、選択すると詳細が表示される。
